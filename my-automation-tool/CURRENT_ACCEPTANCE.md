# Z 完美压枪宏：物理左键联动验收

> 验收状态：2026-08-14 用户确认以下功能全部通过。

## ⚠️ 安全准备

| 检查 | 请这样做 |
|---|---|
| 测试环境 | 优先进入你允许使用宏的训练营；不要在桌面图标、重要文件或在线对战中测试。 |
| 使用脚本 | 在宏库选择 `z-完美压枪宏.py`，然后点击“重新加载”。 |
| 触发键 | 保持为反斜杠键 `\`，不要改成鼠标左键。 |
| 停止方法 | 再按一次反斜杠可停止；紧急时也可以使用全局禁用键或直接退出程序。 |

## 验收图表

```text
按一次反斜杠
      ↓
开启左键监听 ── 左键未按 ──→ 只等待，不移动
      │
      └──────── 左键按住 ──→ 持续压枪
                              ↓
                         左键松开
                              ↓
                       停止移动，继续等待
```

## 验收步骤

| 序号 | 操作 | 正确结果 |
|---:|---|---|
| 1 | 启动程序，选择并重新加载 `z-完美压枪宏.py` | 宏有效；触发键显示为反斜杠；模式显示为切换。 |
| 2 | 按一次反斜杠，但不要按鼠标左键，等待约 3 秒 | OSD 显示宏已启动；鼠标完全不移动，也不会自动点击左键。 |
| 3 | 亲手按住鼠标左键约 1 秒 | 鼠标开始按初版曲线向下压；每 8 步仍会执行初版的“松开—100ms±10ms—重新按下”点射重置。 |
| 4 | 松开鼠标左键 | 压枪立即停止；等待期间不会重新模拟按下，宏继续等待下一次物理左键。 |
| 5 | 再次按住鼠标左键 | 不需要再按反斜杠，压枪会再次开始。 |
| 6 | 再按一次反斜杠，然后继续按住左键 | OSD 显示宏已停止；此后左键仍能正常使用，但鼠标不再自动下移。 |

## 通过标准

以下四点全部正确即可通过：

1. 反斜杠只负责开启或关闭监听。
2. 物理左键不按时绝不移动。
3. 物理左键按住时压枪，松开后立即停止移动。
4. 初版的点射重置、发数、随机毫秒、下压随机和扇形算法全部保留；只有物理左键按住时才允许执行。
