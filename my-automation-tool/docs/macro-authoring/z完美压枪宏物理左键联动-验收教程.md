# z-完美压枪宏：物理左键联动验收记录

> 2026-08-14：用户确认本轮全部通过。

| 项目 | 已验收行为 |
|---|---|
| 启停 | `HOTKEY='backslash'`；按一次开启监听，再按一次停止。 |
| 左键联动 | 物理左键未按时不移动；按住时压枪；松开后停止移动并继续等待。 |
| 输入边界 | 只读取真实物理状态；本程序 `MAPL` 模拟输入不计入。 |
| 初版算法 | 三阶段随机、每8步点射重置、100ms±10ms、下压随机与扇形跟随全部保留。 |
| 安全停止 | 点射等待期间若物理左键松开，不会再次模拟按下；反斜杠停止和退出均可中断。 |

注意：“每8步”表示八次鼠标下压步骤，并不等于程序读取到游戏真实射出八发。项目不读取武器、弹药或游戏内存；若未来要求按真实射速校准，需要由用户提供具体武器的每发间隔。

完整操作表保存在项目根运行目录的 `CURRENT_ACCEPTANCE.md`。
