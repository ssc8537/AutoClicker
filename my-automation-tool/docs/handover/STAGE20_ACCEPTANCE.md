# Stage 20｜自动压枪与麦克风预检验收

> 当前状态：程序已实现并完成自动检查，用户已完成 Windows 人工验收。本文件保留操作步骤、通过标准和安全边界，供后续复核。

## 测试准备

| 项目 | 当前设置 |
|---|---|
| 正式程序 | `my-automation-tool\dist\MyAutoPlayer\MyAutoPlayer.exe` |
| 压枪脚本 | `my-automation-tool\macros\z-自动压枪宏.py` |
| 触发键 | 反斜杠键 `\` |
| 触发方式 | 按住运行，松开停止 |
| 当前压枪量 | 每 15ms 向下移动 1 个相对单位 |
| 随机化 | 本轮没有加入 |

## 第 1 项：先在安全窗口测试压枪

1. 先从任务栏或托盘完全退出旧版 MyAutoPlayer，避免单实例把你带回旧程序。
2. 打开上表中的 Stage 20 正式程序，进入“宏库”。
3. 找到并选中 `z-自动压枪宏`，确认它已启用。
4. 打开 Windows“画图”或其他没有重要内容的空白窗口。
5. 把光标放在空白区域，按住反斜杠键 `\` 约 1 秒，再松开。

正确结果：

- 按住期间鼠标左键保持按下。
- 光标持续、缓慢地向下移动。
- 松开反斜杠后，光标立即停止继续向下，鼠标左键被释放。
- 程序不应出现左键一直卡住的情况。

## 第 2 项：在游戏安全训练区域测试

1. 只进入允许练习的训练区域，不要首次在重要对局中测试。
2. 把准星放在安全目标上。
3. 按住反斜杠键：应持续开火，同时准星按固定速度向下移动。
4. 松开反斜杠键：应停止开火和继续下移。

如果下移太快或太慢，只反馈第 2 项和你的感觉即可。例如：

```text
第 2 项：功能正确，但向下移动太快，大约希望改成当前速度的 50%。
```

Windows 指针速度、增强指针精确度、游戏灵敏度和游戏是否接受 `SendInput` 都会影响实际距离。本轮只确认固定压枪功能，不验收随机化。

## 第 3 项：麦克风默认关闭

1. 重新启动程序，进入“开发连招”。
2. 查看“实时声音状态”。
3. 找到“麦克风预检：关闭（点击开启）”。

正确结果：

- 每次启动默认显示关闭。
- 麦克风状态条显示“麦克风预检已关闭”。
- 此时桌面声音状态仍可随音乐跳动。
- 此时程序不应为了空闲预检打开麦克风。

## 第 4 项：手动开启麦克风预检

1. 点击“麦克风预检：关闭（点击开启）”。
2. 按钮应变为“麦克风预检：开启（正在检测）”。
3. 对着所选麦克风说“喂喂喂，123”。

正确结果：麦克风状态条随声音跳动。这个开关只用于空闲设备预检；录像是否保存麦克风仍由上方“录制麦克风声音”单独决定。

再次点击关闭后，麦克风条归零并显示“麦克风预检已关闭”，桌面声音条继续正常预检。

## 最终通过标准

| 编号 | 通过条件 |
|---:|---|
| 1 | 安全窗口中按住即左键按下并向下移动，松开立即全部停止。 |
| 2 | 游戏训练区域能够持续开火并产生固定向下压枪效果。 |
| 3 | 程序每次启动时麦克风预检默认关闭，桌面声音预检不受影响。 |
| 4 | 用户主动开启后麦克风条真实跳动，再关闭后停止麦克风预检。 |
